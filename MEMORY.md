# Memory

- The project is a global, security-aware observatory for public Machine Payments Protocol services. It deliberately performs only harmless, unauthenticated HTTP discovery and observation.
- GitHub is the source host.
- The selected runtime is one TypeScript Cloudflare Worker managed with npm and Wrangler. D1 holds the normalized index and crawl state, R2 holds bounded redacted observation documents, Queues deliver crawl work, and a six-hour Cron schedules discovery and due recrawls. Durable Objects are not currently needed.
- The production Worker is `mpp-ninja` at `https://mpp-ninja.bcrt43.workers.dev`; initial verified version `4885040a-9061-4bba-ae75-1d0080546439` came from Git SHA `eba6fedf072aaa1bcb25b220224a1bb0efd13883`.
- The primary production URL is `https://mpp.ninja`, configured as a Worker Custom Domain. Historical initial custom-domain version `d4e09698-0b36-45ad-a3dc-9ade4e2993a1` came from Git SHA `97cad32c21d1f8d9b058eba36b6751a4740ff589`; the `workers.dev` fallback remains enabled and preview URLs are disabled.
- The configured production resources are D1 `mpp-observatory`, R2 `mpp-observations`, Queue `mpp-crawl`, and dead-letter Queue `mpp-crawl-dlq`. All are provisioned, migration `0001_observatory.sql` is applied to remote D1, and the enabled `observations-30d` lifecycle expires `observations/` objects after 30 days. Queue consumption, R2 persistence/readback, and the indexed UI/API were verified against observatory commit `d5569bf90f66ceed1324fae8b0249efe9c3fd55a`, deployed as Worker version `f2ac74be-2aa7-4411-b538-64a40b4a25d2`.
- Discovery sources are the query-free canonical paths from `serviceUrl` values in `https://mpp.dev/api/services`, an anonymous bounded fallback over MPPScan's embedded `originUrls`, advertised OpenAPI 3.x `x-payment-info`, and normalized manual submissions. Keep source provenance separate from runtime `402` evidence.
- The scanner's defense-in-depth policy combines `global_fetch_strictly_public` with URL/scheme/port checks, exact service-hostname confinement, private and reserved address rejection, repeated DNS validation at every allowed hop, cross-host redirect rejection, self-target and HTTPS-downgrade blocking, manual redirect limits, timeouts, response-size limits, deterministic jitter, per-origin leases, and secret redaction. Cross-host advertised metadata may be retained but is not fetched.
- Advertised/redirect queries are removed rather than replayed. R2 evidence stores a body digest and byte count, never response-body content. Opaque provider payment/transaction identifiers are redacted while numeric economic/session inputs remain observable. Crawl dedupe keys include service, endpoint, probe kind, and normalized URL; queue-send failure remains retryable, and producer batches stay below Cloudflare's count and byte limits.
- D1 budget invariants are one consumer message per invocation, at most one catalog endpoint, OpenAPI offer, RFC 9727 scheduling link, or due-target scheduling unit per message; 160 catalog/OpenAPI endpoints, 512 OpenAPI offers, 16 RFC 9727 links, and 192 active/256 retained crawl targets per service; at most eight parsed Payment challenges; and trigger-backed offer/security history. Catalog/OpenAPI revision clocks are separate from runtime `last_seen`; stale `enqueueing` reservations recover after five minutes.
- Manual candidates receive only a fixed base/OpenAPI/API-catalog pass until a valid runtime `402` or currently active trusted target provenance promotes them. Five-minute admission limits are 6 per window-scoped client digest and 120 globally; no raw client address is retained. Every unconfirmed status counts toward caps of 8 per origin and 500 globally, authority expires after 24 hours, and terminal manual-only records are pruned after 30 days.
- Complete per-service source snapshots and whole-catalog barriers stage and atomically publish current service, endpoint, offer, and crawl-target membership. Terminal and 24-hour stale failures clean staging while retaining the prior published revision. A delayed older message cannot override a newer completed withdrawal; withdrawing the sole OpenAPI parent also withdraws its derived data and child probes until a fresh restoration crawl.
- R2 observation objects have a 30-day lifecycle. D1 keeps the body digest and normalized summary after clearing expired object pointers; bounded Cron retention compacts older repeat observations and terminal manual-only state after 30 days and obsolete coordination runs after 14 days while preserving current authority and published-service change history.
- Runtime observed-MPP classification requires HTTP `402` and the current draft's structural challenge fields (`id`, `realm`, lowercase `method`, valid `intent` syntax, and a decodable JSON `request`).
- The verified live mpp.dev shape includes `payment: null` for endpoints without an advertised offer. Payment challenge parsing must isolate valid Payment challenges in mixed authentication-scheme headers, and high-confidence OpenAPI fingerprints require named implementation/generator fields rather than arbitrary prose.
- Security properties use only `observed`, `inferred`, `tested-pass`, `tested-fail`, `unknown`, or `not-tested`. Fingerprints are evidence-scored and version-agnostic; public advisories and economic-security research classes are prior art unless direct evidence establishes applicability.
- Use Node 24 from `.nvmrc`; Node 23 is unsupported by the current test stack.
- `AGENTS.md` is the canonical operating guide; `FEATURES.md` is the product and acceptance tracker.
